# 📦 Sing-Box Extended Installer

Интерактивный установщик и обновлятор [sing-box-extended](https://github.com/shtorm-7/sing-box-extended) для OpenWrt и совместимых Linux-систем.


## 🚀 Использование

### Однострочная установка через `wget`

```sh
sh <(wget -qO- https://raw.githubusercontent.com/dnrshtnk/OpenWRT-sing-box-extended/refs/heads/main/install.sh)
```

### Однострочная установка через `curl`

```sh
sh <(curl -sSL https://raw.githubusercontent.com/dnrshtnk/OpenWRT-sing-box-extended/refs/heads/main/install.sh)
```

Оригинальный форк: [OpenWRT-sing-box-extended](https://github.com/EikeiDev/OpenWRT-sing-box-extended)
